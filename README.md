# 写真つき手順カード

100日100プロダクトチャレンジ Day095（2026-11-10）

スマホで撮った写真に1行ずつ説明を付けて手順を並べると、A4の1枚に収まった手順カードになるWebページです。

- 作業の名前を入れ、手順を最大6つ並べます。1つの手順は「写真（任意）＋説明1行（40字まで）」です
- 気をつけてほしい手順には「ここ注意」を付けられます（赤い枠と「注意」の札、注意の一言）
- 手順は「上へ」「下へ」で並べ替えられます
- 印刷（A4縦1枚）と、画像で保存（LINEなどでスタッフに送る用）ができます。iPhone・iPadは共有シートから、使えないときは長押しで保存します

## 使い方

`index.html` をブラウザで開きます。「見本を入れる（開店前の準備）」で架空の例を入れられます（見本の写真の代わりに簡単な絵を描きます）。

## 扱うデータ

- 写真と入力した文字を、当サイトのサーバーに送る仕組みはありません
- 文字の下書きはこの端末のブラウザ（localStorage）に、写真の下書きは IndexedDB に残ります。ブラウザの設定などで消えることがあります
- 写真は読み込むときに長辺1280pxに縮め、描き直してJPEGにします
- お客さまの顔や名前、お金・伝票などが写っていないかは、使う人が確かめてください。このページは写っているものを見分けません
- アクセス解析（Cloudflare Web Analytics）でページの閲覧状況を計測しています

## 使用技術

HTML / CSS / JavaScript（ライブラリなし・HTML1枚）。手順カードは canvas に描き、印刷もその画像をA4に出します。
